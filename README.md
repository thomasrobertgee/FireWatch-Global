# 🚒 FireWatch Global

**Intelligence delivered at shift change. 0700 hours.**

FireWatch Global is a high-level briefing tool designed for the global firefighting community. It aggregates, filters, and summarizes real-time intelligence on operations, welfare, innovation, and health to provide actionable insights for fire service professionals.

## ⚡ Tech Stack

*   **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
*   **Database & Auth:** [Supabase](https://supabase.com/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **AI Intelligence:** [Google Gemini 1.5 Flash](https://deepmind.google/technologies/gemini/)
*   **Data Source:** [NewsAPI](https://newsapi.org/)
*   **Email Infrastructure:** [Resend](https://resend.com/)

## 🤖 Automation Architecture: The Scout Agent

FireWatch Global utilizes a unique "Scout Agent" workflow to bypass serverless execution limits (e.g., Vercel Hobby Tier timeouts) while performing heavy AI processing.

1.  **Trigger:** A GitHub Action (`scout-trigger.yml`) runs on a schedule (e.g., every 6 hours).
2.  **Execution:** This action hits a secured API endpoint (`/api/scrape`) on the Next.js app.
3.  **Processing:** The application fetches raw news, filters for relevance using simple heuristics, and then uses **Gemini AI** to generate:
    *   **Card Summaries:** Punchy, 220-char briefs for the dashboard.
    *   **Full Summaries:** Structured 5-paragraph deep dives with quotes.
    *   **Categorization:** Auto-tagging (Operations, Welfare, etc.).
4.  **Storage:** Processed articles are stored in Supabase for fast, static-like retrieval by the frontend.

## 🚀 Key Features

*   **Command Dashboard:** A visually immersive, high-density grid of operational briefings, filtered by region and category.
*   **The Health Ledger:** A dedicated, peer-reviewed section tracking medical studies and health legislation impacting firefighters (e.g., PFAS, presumptive legislation).
*   **Shift Change Newsletter:** An automated daily email briefing sent to subscribers, featuring a dynamic "Shift Intro" generated by AI to match the tone of the day.
*   **Fire Danger Gauge:** A localized, visual representation of fire danger ratings (integrated via weather APIs).

## 🛠️ Getting Started

To run FireWatch Global locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/thomasrobertgee/FireWatch-Global.git
    cd FireWatch-Global
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure Environment Variables:**
    Create a `.env.local` file in the root directory and add the following keys:

    ```env
    # Supabase (Database & Auth)
    NEXT_PUBLIC_SUPABASE_URL=
    SUPABASE_SERVICE_ROLE_KEY=

    # AI & Data
    GEMINI_API_KEY=
    NEWS_API_KEY=

    # Email
    RESEND_API_KEY=

    # Security
    CRON_SECRET=
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) with your browser.

## 🌍 Deployment

FireWatch Global is optimized for deployment on **Vercel**.

1.  **Connect Repo:** Link your GitHub repository to a new Vercel project.
2.  **Environment Variables:** Copy all keys from your `.env.local` to the Vercel Project Settings.
3.  **Cron Jobs:** The `vercel.json` file (if applicable) or the GitHub Action serves as the cron trigger to ensure fresh content is fetched regularly without relying on user traffic.
